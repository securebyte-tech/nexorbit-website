# Security Policy

NexOrbit maintains the public website at https://nexorbit.tech/, deployed from the `main` branch of this repository.

## Supported Versions

| Deployment | Security updates |
| --- | --- |
| Current live website (`main`) | Supported |
| Older commits, archived copies, and forks | Not actively supported |

## Reporting a Vulnerability

Please **do not open a public GitHub issue** to disclose a security vulnerability.

1. **Preferred:** If private vulnerability reporting is enabled, use GitHub's [private vulnerability report form](https://github.com/securebyte-tech/nexorbit-website/security/advisories/new).
2. **Fallback:** If that form is unavailable, email [nexorbit.business@gmail.com](mailto:nexorbit.business@gmail.com?subject=NexOrbit%20Security%20Report) with the subject `NexOrbit Security Report`. Do not include passwords, API keys, or other secrets in your message.

A useful report should include:
- A concise description of the issue and its potential impact.
- The affected URL, feature, or file.
- Clear steps to reproduce the issue safely, if possible.
- Any suggested mitigation, if known.

We will review reports as resources allow. We cannot guarantee a specific response or remediation timeframe.

## Responsible Disclosure

Please give us an opportunity to investigate before making vulnerability details public. Do not access data you do not own, extract private information, disrupt services, or perform destructive testing. Testing is limited to systems and data you are authorized to assess.

## Scope

This policy covers the public NexOrbit website and the source code in this repository. External services such as GitHub and Hostinger are governed by their own security policies.
